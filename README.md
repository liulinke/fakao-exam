# 法考模拟考试系统

一个纯前端静态部署的法律职业资格考试（法考）模拟练习网站，内置两套精选题库（原版题库 + 进阶难题题库），支持模拟考试、错题复盘和学习统计。

## 在线体验 & 源码

- 🌐 在线访问：<https://www.liulinke.com/p/fakaomoni/>
- 📦 开源仓库（Gitee）：<https://gitee.com/liulinker/fakao-exam>

## 功能特性

- **两套题库可选**：原版 724 道精选题 + 进阶 800+ 道难题，可自由切换
- **在线模拟考试**：按真实考试节奏答题，交卷后自动评分
- **错题复盘**：集中查看做错的题目，巩固薄弱知识点
- **学习统计分析**：统计各科目正确率、答题进度等数据
- **纯前端静态部署**：无需后端服务，可直接部署到任意静态服务器或 CDN

## 题库说明

本项目包含两套题库，覆盖法考全部 17 个科目：

| 题库 | 目录 | 题目数量 | 特点 |
|------|------|---------|------|
| **原版题库** | `data/bank/` | 724 道 | 精选题目，难度适中，适合入门练习 |
| **进阶题库** | `data/bank_hard/` | 800+ 道 | 案例分析型题目，难度偏高，侧重深度考察 |

两套题库的文件结构完全一致，应用始终从 `data/bank/` 目录加载数据，通过切换脚本交换目录来实现题库切换。

## 如何切换题库

### 方法一：使用切换脚本（推荐）

```bash
# 查看当前激活的题库
./switch_bank.sh status

# 切换题库（原版 ↔ 进阶 互换）
./switch_bank.sh swap

# 查看帮助
./switch_bank.sh help
```

脚本会自动交换 `data/bank/` 和 `data/bank_hard/` 两个目录的内容，应用代码无需任何修改。

### 方法二：手动切换

```bash
# 切换到进阶题库
mv data/bank data/_bank_original
mv data/bank_hard data/bank
mv data/_bank_original data/bank_hard

# 切换回原版题库（反向操作）
mv data/bank data/bank_hard
mv data/_bank_original data/bank   # 注意：需要 _bank_original 存在
```

### 切换后注意事项

1. **刷新浏览器**即可使用新题库
2. **PWA 离线用户**：如果启用了 Service Worker 离线缓存，切换后建议在浏览器开发者工具中清除 SW 缓存，或将 `sw.js` 中的 `CACHE_VERSION` 加 1 以触发缓存更新
3. **切换前请确保**没有正在进行的模拟考试（否则成绩可能错乱）
4. 每次运行 `./switch_bank.sh swap` 都会在两套题库之间来回切换

## 科目覆盖

两套题库均覆盖以下法考客观题全部 17 个科目：

**试卷一**：刑法、刑事诉讼法、行政法与行政诉讼法、法理学（含法治思想）、宪法、国际法、司法制度与法律职业道德、中国法律史

**试卷二**：民法、民事诉讼法（含仲裁）、商法、经济法、知识产权法、国际私法、国际经济法、环境资源法、劳动与社会保障法
