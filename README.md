# 法考模拟考试系统

一个纯前端静态部署的法律职业资格考试（法考）模拟练习网站，内置精选题库，支持模拟考试、错题复盘和学习统计。

## 在线体验 & 源码

- 🌐 在线访问：<https://www.liulinke.com/p/fakaomoni/>
- 📦 开源仓库（Gitee）：<https://gitee.com/liulinker/fakao-exam>

## 功能特性

- **724 道精选法考题库**，覆盖民法、刑法、行政法、经济法、国际法等多个法律部门
- **在线模拟考试**：按真实考试节奏答题，交卷后自动评分
- **错题复盘**：集中查看做错的题目，巩固薄弱知识点
- **学习统计分析**：统计各科目正确率、答题进度等数据
- **纯前端静态部署**：无需后端服务，可直接部署到任意静态服务器或 CDN
