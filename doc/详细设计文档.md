# 法考模拟考试网站 · 详细设计文档

版本 v1.0 ｜ 日期 2026-07-06 ｜ 状态：待确认

---

## 1. 项目概述

为国家统一法律职业资格考试（法考）**客观题**部分构建一个纯前端模拟考试网站，包含：

- 一个 AI 生成为主、参考历年真题风格与考点分布的原创题库（JSON 格式）
- 一个无需服务器的静态网站，支持整卷模拟、科目练习、错题本与统计

**范围说明**：仅覆盖客观题（选择题），不含主观题（笔试）。单用户使用，数据存本地浏览器。

---

## 2. 真实考试结构参考（组卷依据）

客观题考试分试卷一、试卷二，每卷 100 题、150 分、180 分钟，两卷合计 300 分，合格线 180 分（全国统一标准）。

每卷题型构成：

| 题型 | 题量 | 每题分值 | 小计 |
|---|---|---|---|
| 单项选择题 | 50 | 1 分 | 50 分 |
| 多项选择题 | 35 | 2 分 | 70 分 |
| 不定项选择题 | 15 | 2 分 | 30 分 |

科目分布：

- **试卷一**：习近平法治思想、法理学、宪法、中国法律史、国际法、司法制度和法律职业道德、刑法、刑事诉讼法、行政法与行政诉讼法
- **试卷二**：民法、知识产权法、商法、经济法、环境资源法、劳动与社会保障法、国际私法、国际经济法、民事诉讼法（含仲裁制度）

各科目每卷题量配额（参考近年真题分布，设计为可配置项）：

| 试卷一科目 | 约占题量 | 试卷二科目 | 约占题量 |
|---|---|---|---|
| 刑法 | 22 | 民法 | 28 |
| 刑事诉讼法 | 22 | 民事诉讼法(含仲裁) | 24 |
| 行政法与行政诉讼法 | 20 | 商法 | 18 |
| 法理学(含法治思想) | 12 | 经济法 | 8 |
| 宪法 | 8 | 知识产权法 | 6 |
| 国际法 | 5 | 国际私法 | 5 |
| 司法制度与职业道德 | 6 | 国际经济法 | 5 |
| 中国法律史 | 5 | 环境资源/劳动社保 | 6 |

> 配额存放于 `config.json`，可随大纲变化调整，组卷算法按此抽题。

## 3. 总体架构

**形态**：纯静态网站。HTML + CSS + 原生 JavaScript（ES Modules），无构建步骤，无后端。可直接本地打开（配合 `python -m http.server`）或托管到任意静态空间（GitHub Pages / Cloudflare Pages / 国内 OSS）。

**外部依赖**：仅 Chart.js（统计图表），从 **cdnjs.cloudflare.com** 加载并提供本地 fallback 副本（jsdelivr 在国内网络不可用，不采用）。其余零依赖。

**目录结构**：

```
fakao-exam/
├── index.html              # 首页（入口/导航/数据概览）
├── exam.html               # 模拟考试页
├── practice.html           # 科目练习页
├── review.html             # 错题本页
├── stats.html              # 统计分析页
├── result.html             # 成绩报告页
├── css/
│   └── main.css
├── js/
│   ├── app.js              # 公共初始化、导航
│   ├── bank.js             # 题库加载与索引（fetch 分片 JSON）
│   ├── paper.js            # 组卷算法
│   ├── exam.js             # 考试流程状态机（计时/答题卡/交卷）
│   ├── practice.js         # 练习模式逻辑
│   ├── grader.js           # 判分器
│   ├── store.js            # localStorage 封装 + 导入导出
│   ├── stats.js            # 统计计算
│   └── vendor/chart.min.js # 本地 fallback
└── data/
    ├── config.json          # 科目配额、题型配额、时长、合格线
    ├── manifest.json        # 题库清单：各分片文件、题数、版本号
    └── bank/
        ├── xingfa.json      # 刑法
        ├── minfa.json       # 民法
        ├── xingsu.json      # 刑事诉讼法
        ├── minsu.json       # 民事诉讼法
        ├── xingzheng.json   # 行政法
        ├── shangfa.json     # 商法
        ├── falixue.json     # 法理学（含法治思想）
        ├── xianfa.json      # 宪法
        └── ...              # 其余科目各一个分片
```

按科目分片的原因：练习模式只需加载单科；模拟考试并行 fetch 全部分片；单文件过大影响首屏。

## 4. 题库设计

### 4.1 数据模型（单题 JSON Schema）

```json
{
  "id": "MF-0128",
  "subject": "minfa",
  "subjectName": "民法",
  "chapter": "合同的效力",
  "type": "single",
  "stem": "甲将自有房屋出售给乙……下列说法正确的是？",
  "options": {
    "A": "……",
    "B": "……",
    "C": "……",
    "D": "……"
  },
  "answer": ["C"],
  "analysis": "本题考查无权处分与善意取得。根据《民法典》第311条……A项错误，因为……；B项……；C项正确……；D项……",
  "difficulty": 3,
  "tags": ["善意取得", "无权处分"],
  "lawBasis": ["《民法典》第311条"],
  "styleRef": "参考2023年真题风格",
  "version": "2026-07"
}
```

字段说明：

- `type`：`single`（单选）/ `multi`（多选）/ `indeterminate`（不定项）
- `answer`：统一为数组，单选长度为 1，便于判分器统一处理
- `analysis`：**必须逐项解析**（每个选项为何对/错），这是模拟题的核心价值
- `difficulty`：1–5，组卷时可控制难度分布（目标均值约 3）
- `lawBasis`：法条依据，便于核对与更新
- `id` 前缀按科目编码（MF=民法、XF=刑法……），全库唯一

### 4.2 题库规模规划

| 阶段 | 每科目标 | 全库规模 | 说明 |
|---|---|---|---|
| MVP | 大科 60 题 / 小科 20 题 | ~500 题 | 够组 2 套完整卷 + 基础练习 |
| 一期 | 大科 150 / 小科 50 | ~1500 题 | 组卷抽题不重复度明显提升 |
| 完整 | 大科 300 / 小科 100 | ~3000 题 | 长期刷题不枯燥 |

每科内部题型比例与真实卷一致：约 50% 单选、35% 多选、15% 不定项。

### 4.3 生成流程（混合策略）

1. **考点清单**：按最新法考大纲整理各科章节考点清单（存 `chapters.md`，作为生成时的输入约束）
2. **风格校准**：分析历年真题的命题特征——案例化题干、"下列说法正确/错误的是"句式、干扰项设计手法（偷换概念、张冠李戴、绝对化表述）
3. **批量生成**：按「科目 × 章节 × 题型 × 难度」四维配额生成原创题，每题强制附逐项解析与法条依据
4. **质量控制**：
   - 自动校验：JSON schema 校验、answer 合法性（单选恰 1 个、多选 ≥2 个）、选项数=4、id 唯一
   - 法条核对：抽样核对 `lawBasis` 引用的现行法条内容（重点：民法典、刑法修正案、新修诉讼法）
   - 时效标注：每题带 `version`，法律修订后按科目批量复核
5. **入库**：脚本合并为分片 JSON + 更新 `manifest.json`

> **免责声明**（网站页脚展示）：题目为 AI 生成的原创模拟题，仅供练习，不代表真题；解析法条以现行有效版本为准。

## 5. 功能设计

### 5.1 模拟考试模式

**组卷算法**（`paper.js`）：

1. 读取 `config.json` 中所选卷别（卷一/卷二）的科目配额与题型配额
2. 对每个科目，按题型比例从该科题池随机抽题；排除近 2 次模拟考中出现过的题（记录在 store 中，可关闭）
3. 难度平衡：全卷难度均值控制在 2.8–3.2，超出则换题重抽
4. 洗牌规则：同题型内打乱顺序，但保持真实卷结构——第 1–50 题单选、51–85 多选、86–100 不定项

**考试流程状态机**：`ready → in_progress → submitted`（真实考场模式下无暂停态）

**计时系统（尽量还原真实机考）**：

- 180 分钟倒计时常驻顶栏，剩 30/10/5 分钟分级提醒（变色 + 弹窗），归零**强制自动交卷**
- 计时基于绝对时间戳（开考时刻 + 180min），而非页面内累加——切标签页、锁屏、断电重开，时间照常流逝，和真实考场一致
- **真实考场模式（默认）**：不可暂停、不可中途退出重来（关闭页面重开只能继续剩余时间或作废本次）、答题期间不显示对错
- **练习考模式（可选开关）**：允许暂停，供碎片时间使用
- 逐题耗时记录：后台记录每题停留时长，成绩报告中给出「用时最长的 10 题」和各科目耗时占比，帮助训练做题速度（真实考场平均每题仅 1.8 分钟）

**考场还原细节**：

- 进入考试自动请求浏览器全屏；退出全屏弹出提示（模拟监考警告，可关闭该行为）
- 界面布局仿照司法部机考系统：左侧题干与选项、右侧答题卡、顶部倒计时与考生信息栏
- 开考前有「考试须知」确认页 + 3 秒倒计时开考
- 答题卡侧栏：100 格，已答/未答/标记三种状态，点击跳题；支持「标记本题」稍后回看
- 进度实时写入 localStorage：意外关闭页面后重开，倒计时按绝对时间继续
- 交卷前确认：提示未答题数与剩余时间；剩余时间不足 5 分钟时未答题格闪烁提醒

**判分规则**（`grader.js`）：

- 单选：答对得 1 分
- 多选：与标准答案完全一致得 2 分，多选/少选/错选均 0 分（与真实规则一致）
- 不定项：完全一致得 2 分；此外提供「严格模式/宽松模式」开关，宽松模式下少选按比例给分（默认严格）

### 5.2 成绩报告（result.html）

- 总分、用时、是否达到合格线折算（单卷 ≥90 视为达标参考）
- 分科目得分率条形图 + 题型得分率
- 全卷逐题回看：题干、我的答案 vs 正确答案、解析；错题自动进入错题本

### 5.3 科目练习模式

- 筛选维度：科目（必选）→ 章节（可多选）→ 题型 → 难度
- 顺序/随机两种出题顺序；答完一题立即判分并展示解析
- 记录练习进度（每科已刷题 id 集合），支持「只做没做过的题」
- 快捷键：1–4/A–D 选择，回车提交，→ 下一题

### 5.4 错题本（review.html）

- 自动收集：模拟考与练习中的错题（记错误次数、最近错误时间）
- 列表视图：按科目/错误次数/时间排序与筛选
- 「错题重做」：从错题本组卷再练，答对 2 次后可自动移出（可配置）
- 手动操作：移除、加星（重点标记）

### 5.5 统计分析（stats.html）

- 科目雷达图：各科正确率（Chart.js radar）
- 历次模拟考成绩折线图（可看趋势）
- 刷题日历热力图（每日刷题量，纯 CSS grid 实现）
- 薄弱点榜单：正确率最低的 10 个章节/tag，点击直达练习

## 7. 本地数据存储（store.js）

localStorage key 设计（前缀 `fk_`，总量控制在 2MB 内）：

| Key | 内容 |
|---|---|
| `fk_exam_active` | 进行中考试快照（卷面题目 id 列表、已答、剩余时间），交卷后清除 |
| `fk_exam_records` | 历次模拟考记录数组（时间、卷别、总分、分科得分、逐题作答，最多留 30 次） |
| `fk_wrong` | 错题字典 `{qid: {count, lastAt, starred}}` |
| `fk_practice` | 各科已刷题 id 集合 + 正误计数 |
| `fk_settings` | 深色模式、判分模式、排除重复题开关 |

**导入/导出**：设置页提供一键导出全部数据为 JSON 文件、导入恢复——弥补 localStorage 清缓存丢数据的风险，也支持换设备迁移。

## 9. 风险与对策

- **题目准确性**：AI 生成题可能有法律错误 → 逐项解析 + 法条依据强制字段，便于人工抽查；页面提供「报错」按钮把可疑题 id 记入本地列表，导出后修订
- **法律时效**：法律法规修订导致题目过期 → 每题 `version` + `lawBasis`，修法后按科目批量筛查
- **localStorage 容量/丢失**：题库放静态 JSON 不占存储；用户数据支持导出备份
- **真题版权**：不收录真题原文，仅参考风格与考点分布，规避版权风险
