# 法考模拟 · 部署到 www.liulinke.com/p/fakaomoni.html

我无法直接登录你的 VM（本环境无法访问 39.105.114.207，也没有你的 SSH 凭据），所以下面是你自己执行的步骤。全程约 3 分钟。

> ⚠️ 重要：`www.liulinke.com` 已经能打开，说明 **80 端口已有 Web 服务在跑**（很可能是 nginx，不一定是 Apache）。
> **不要盲目安装并启动 Apache**——那会和现有服务抢 80 端口，可能让你整个网站瘫痪。
> 正确做法：先看清现在跑的是什么，把文件放进它的网站根目录即可。

---

## 第 1 步：把安装包传到 VM

在**你的 Mac 终端**里（`deploy` 文件夹所在位置）执行，把两个文件传上去：

```bash
cd "路径/法考模拟考试网站/deploy"
scp fakaomoni.tar.gz deploy_fakao.sh root@39.105.114.207:/root/
```

（如果不是 root 用户，把 `root` 换成你的登录名。）

## 第 2 步：登录 VM，看清现在的 Web 服务器

```bash
ssh root@39.105.114.207

# 看 80 端口是谁在跑
sudo ss -ltnp | grep ':80'
# 输出里有 nginx / apache2 / httpd 就是对应的服务器
```

同时确认 **网站根目录**（就是 www.liulinke.com 对外提供文件的目录）：

```bash
# 如果是 nginx：
grep -R -n "root " /etc/nginx/ 2>/dev/null | grep -v '#'
# 如果是 apache：
grep -R -n "DocumentRoot" /etc/apache2 /etc/httpd 2>/dev/null
```

记下那个目录，例如 `/var/www/html` 或 `/www/wwwroot/www.liulinke.com`。

## 第 3 步：部署（一条命令）

把上一步记下的根目录填在最后：

```bash
cd /root
sudo bash deploy_fakao.sh /你的网站根目录
# 例如： sudo bash deploy_fakao.sh /www/wwwroot/www.liulinke.com
```

脚本会：把网站解压到 `根目录/p/fakaomoni/`，并在 `根目录/p/fakaomoni.html` 放一个自动跳转页。

## 第 4 步：验证

浏览器打开 **https://www.liulinke.com/p/fakaomoni.html** —— 会自动进入 `/p/fakaomoni/` 的应用首页。

## 如果 80 端口确实没有任何服务（需要装 Apache）

只有当 `ss -ltnp | grep ':80'` **没有任何输出**时，才安装 Apache：

**Ubuntu / Debian：**
```bash
sudo apt update && sudo apt install -y apache2
sudo systemctl enable --now apache2
# 根目录为 /var/www/html
```

**CentOS / 阿里云 Linux / RHEL：**
```bash
sudo yum install -y httpd     # 或 sudo dnf install -y httpd
sudo systemctl enable --now httpd
# 根目录为 /var/www/html
```

装好后回到第 3 步，根目录用 `/var/www/html`。
别忘了在**阿里云控制台安全组**放行入方向 80（和 443）端口。

## 常见问题

- **页面能开但题目/样式加载不出来**：多半是 `.js` 文件的 MIME 类型不对。用
  `curl -sI https://www.liulinke.com/p/fakaomoni/js/app.js | grep -i content-type`
  检查，应为 `application/javascript` 或 `text/javascript`。nginx 一般自带，Apache 默认也支持。
- **想让应用就直接是 `fakaomoni.html`（不跳转）**：需要把整个多页应用打包成单文件版，我可以另做一个自包含的 `fakaomoni.html` 给你，告诉我即可。
- **数据说明**：本应用纯前端，所有做题记录存在访问者自己的浏览器里，服务器只提供静态文件，无需数据库。
